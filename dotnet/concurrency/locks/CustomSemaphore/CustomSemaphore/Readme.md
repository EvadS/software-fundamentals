# Реализация собственного семафора на C#

 класс CustomSemaphore с использованием lock/Monitor

 ##  Что такое семафор

Семафор — это примитив синхронизации, который управляет доступом к общему ресурсу через счётчик разрешений (permits).

Поток, желающий войти в критическую секцию, вызывает Wait() (или Acquire()).

Если разрешений больше нуля, счётчик уменьшается, и поток продолжает работу.

Если разрешений нет, поток блокируется до тех пор, пока другой поток не вызовет Release().

Release() увеличивает счётчик разрешений и пробуждает один ожидающий поток.

Таким образом, семафор ограничивает количество потоков, одновременно работающих с ресурсом.
